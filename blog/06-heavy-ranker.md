## なぜあのツイートが上位表示されるのか

タイムラインを開くたびに、不思議に思ったことはありませんか？

「なぜフォロワー100人のアカウントのツイートが、有名人より上に表示されるのか？」  
「いいねが少ないツイートが、なぜトップに来るのか？」  
「昨日のツイートより、3時間前のツイートが下に表示されるのはなぜ？」

答えは、**Heavy Ranker**にあります。

Xのアルゴリズムは、数十億のツイートの中から「あなたにとって最も価値がある」ツイートを選び出します。その最終判定を行うのがHeavy Rankerです。単純な時系列順でも、いいね数順でもありません。あなたの過去の行動、ツイートの特徴、著者の信頼度、そしてリアルタイムのエンゲージメント傾向――これらすべてを統合して、瞬時にスコアを計算しています。

この記事では、Heavy Rankerがどのようにツイートをスコアリングし、あなたのタイムラインを構築しているのか、その仕組みを詳しく解説します。

---

## Heavy Rankerとは: Xアルゴリズムの心臓部

Heavy Rankerは、Xの推薦システムにおける**最終スコアリング層**です。

### アルゴリズム全体の流れ

Xのタイムライン生成は、3段階で行われます。

**第1段階: 候補抽出（Candidate Sourcing）**  
数十億のツイートから、あなたに関連する可能性のある約1,500件を抽出します。フォローしているアカウント、似た興味を持つユーザーがエンゲージしたツイート、トレンドなどが含まれます。

**第2段階: 軽量ランキング（Light Ranker）**  
1,500件を数百件に絞り込みます。シンプルな機械学習モデルで、明らかに関連性の低いツイートを除外します。

**第3段階: Heavy Ranker（最終ランキング）**  
数百件のツイートに対して、**6,000の特徴量**を使った高精度なスコアリングを実行し、最終的な表示順位を決定します。

### なぜ「Heavy」なのか？

Heavy Rankerという名前は、その計算の重さ（computational heaviness）に由来します。

- **6,000の特徴量**を各ツイートから抽出
- **15種類のエンゲージメント確率**を予測
- 複雑な**重み付け計算**でスコアを統合

これらの処理は非常に計算コストが高いため、候補を絞り込んだ後にのみ適用されます。しかし、この「重さ」こそが、Xのタイムラインを高度にパーソナライズする秘密です。

## 6,000の特徴量: 何を見ているのか

Heavy Rankerは、各ツイートから**約6,000の特徴量**を抽出して分析します。これらは大きく3つのカテゴリーに分類されます。

### 1. 著者（Author）情報

ツイートを投稿したアカウントに関する情報です。

**主な特徴量:**

- **TweepCred スコア** - アカウントの信頼度（0〜100）
- フォロワー数、フォロー数、フォロー/フォロワー比率
- アカウント年齢（作成からの経過日数）
- 過去の平均エンゲージメント率
- スパム報告の有無
- ブルー認証（X Premium）の有無
- あなたとの関係（フォローしているか、過去にエンゲージしたか）

**影響:**  
同じ内容のツイートでも、TweepCredが80のアカウントと30のアカウントでは、スコアが大きく異なります。信頼性の高い著者のツイートは、優先的に表示されます。

### 2. ツイート（Tweet）特徴

ツイート自体の内容や形式に関する情報です。

**主な特徴量:**

- テキストの長さ、単語数、文章の複雑さ
- メディア添付（画像、動画、リンク）の有無と種類
- ハッシュタグ、メンションの数
- 投稿時刻（曜日、時間帯）
- 返信ツイートか、リツイートか、オリジナルツイートか
- トピックカテゴリ（AI、スポーツ、政治など）
- センチメント分析（ポジティブ/ネガティブ/ニュートラル）
- 言語、絵文字の使用

**影響:**  
動画付きツイートは画像付きより高スコアになる傾向があります。また、あなたが過去に反応したトピックと類似する内容は、優先されます。

### 3. エンゲージメント（Engagement）履歴

ツイートが公開されてからのリアルタイム反応データです。

**主な特徴量:**

- いいね数、リツイート数、返信数、ブックマーク数
- エンゲージメントの速度（投稿後10分間のいいね数など）
- エンゲージしたユーザーのTweepCred分布
- ネガティブシグナル（ブロック、ミュート、「興味なし」の回数）
- 滞在時間（ツイートを見た平均秒数）
- クリックスルー率（リンク付きツイートの場合）

**影響:**  
投稿直後に多くのエンゲージメントを獲得したツイートは、急速にスコアが上昇します。逆に「興味なし」が多いと、表示が抑制されます。

### 特徴量の組み合わせ

Heavy Rankerの強力さは、これら6,000の特徴量を**単独ではなく組み合わせて評価**する点にあります。

例:  
「フォロワー1,000人のアカウント」×「動画付き」×「投稿後10分で50いいね」×「あなたが過去に類似トピックにエンゲージ」→ 高スコア

これにより、単純な指標では測れない「あなたにとっての価値」を正確に予測できます。

## エンゲージメント確率の予測: 15種類のアクション

Heavy Rankerは、6,000の特徴量を分析して、**あなたがそのツイートにどう反応するか**を予測します。

### 予測される15種類のアクション

Heavy Rankerは、以下の15種類のエンゲージメント確率を計算します。

**ポジティブアクション:**

1. **いいね（Like）** - 最も基本的なエンゲージメント
2. **リツイート（Retweet）** - シェア意欲の指標
3. **返信（Reply）** - 深い関与の証
4. **詳細表示（Detail Expand）** - クリックして全文を読む
5. **プロフィール表示（Profile Click）** - 著者に興味を持つ
6. **リンククリック（URL Click）** - 外部コンテンツへの関心
7. **動画視聴（Video View）** - メディアコンテンツへの反応
8. **ブックマーク（Bookmark）** - 後で読みたい高品質コンテンツ

**ネガティブアクション:**

9. **「興味なし」（Not Interested）** - 明示的な拒否
10. **ミュート（Mute）** - 著者の非表示
11. **ブロック（Block）** - 強い拒否反応
12. **スパム報告（Report Spam）** - 最も強いネガティブシグナル

**中立アクション:**

13. **表示時間（Dwell Time）** - ツイートを見た秒数
14. **スクロール速度（Scroll Speed）** - 飛ばしたか、じっくり見たか
15. **再表示（Revisit）** - タイムラインを再読み込みして再度表示されたか

### 予測の仕組み

Heavy Rankerは、**深層ニューラルネットワーク**を使って各確率を予測します。

例えば、あるツイートに対して:

- いいね確率: 12%
- リツイート確率: 3%
- 返信確率: 1%
- 詳細表示確率: 25%
- 「興味なし」確率: 0.5%

これらの確率は、あなたの過去の行動パターンから学習されています。「動画付きツイートにいいねしやすい」「政治トピックはスキップする」といった傾向が反映されます。

## 最終スコア計算式

15種類の確率が予測されたら、最終的なスコアに統合します。

### 重み付け計算

各アクションには、異なる**重み（weight）**が設定されています。

**重みの例:**（Xの公式値ではなく、推定値です）

- いいね: 0.5
- リツイート: 1.0
- 返信: 1.5
- ブックマーク: 2.0
- 詳細表示: 0.3
- 「興味なし」: -5.0
- ミュート: -10.0
- ブロック: -20.0

### スコア計算式

```
最終スコア = Σ（各アクションの確率 × その重み）
```

具体例:

```
スコア = (0.12 × 0.5)    // いいね
       + (0.03 × 1.0)    // リツイート
       + (0.01 × 1.5)    // 返信
       + (0.25 × 0.3)    // 詳細表示
       + (0.005 × -5.0)  // 「興味なし」

     = 0.06 + 0.03 + 0.015 + 0.075 - 0.025
     = 0.155
```

### 追加要素

基本スコアに加えて、以下の要素が調整されます:

**鮮度ボーナス（Freshness）**  
新しいツイートほど高スコア。時間経過とともに減衰します。

**多様性ペナルティ（Diversity）**  
同じ著者や類似トピックが連続すると、スコアが減少します。

**フォロー関係ブースト**  
フォローしているアカウントのツイートは、スコアが1.2〜1.5倍になります。

**パーソナライゼーション乗数**  
あなたの興味プロファイルとの一致度に応じて、スコアが増減します。

## 実例: スコア計算のシミュレーション

実際の例で、Heavy Rankerがどう動くか見てみましょう。

### ケース1: フォロワー少数だが高エンゲージメント

**ツイート情報:**
- 著者: フォロワー500人、TweepCred 65
- 内容: AI技術の解説スレッド（10ツイート）、図解付き
- エンゲージメント: 投稿後30分で50いいね、15リツイート

**あなたの情報:**
- 過去にAI関連ツイートに高頻度でエンゲージ
- この著者をフォローしていない（が、類似興味のユーザーが多数フォロー）

**Heavy Rankerの予測:**
- いいね確率: 18%（あなたの興味と一致）
- リツイート確率: 8%（価値が高いコンテンツ）
- 詳細表示確率: 45%（スレッドなので全文を読む可能性高）
- 「興味なし」確率: 0.2%（低リスク）

**計算:**
```
基本スコア = 0.18×0.5 + 0.08×1.0 + 0.45×0.3 + 0.002×-5.0
          = 0.09 + 0.08 + 0.135 - 0.01
          = 0.295

興味一致ブースト（×1.4） = 0.295 × 1.4 = 0.413
鮮度ボーナス（+0.05） = 0.413 + 0.05 = 0.463

最終スコア: 0.463
```

**結果:** タイムライン上位20%に表示される可能性が高い

### ケース2: 有名人だがあなたの興味外

**ツイート情報:**
- 著者: フォロワー100万人、TweepCred 95
- 内容: セレブのゴシップ、写真1枚
- エンゲージメント: 投稿後1時間で10,000いいね

**あなたの情報:**
- ゴシップ系ツイートに過去ほとんどエンゲージなし
- この著者をフォローしていない

**Heavy Rankerの予測:**
- いいね確率: 2%（興味が低い）
- リツイート確率: 0.5%
- 詳細表示確率: 5%
- 「興味なし」確率: 3%（リスクあり）

**計算:**
```
基本スコア = 0.02×0.5 + 0.005×1.0 + 0.05×0.3 + 0.03×-5.0
          = 0.01 + 0.005 + 0.015 - 0.15
          = -0.12

最終スコア: -0.12
```

**結果:** タイムラインに表示されない可能性が高い

### スコアの意味

この2つの例から、Heavy Rankerの核心が見えてきます:

**「人気」ではなく「あなたにとっての価値」を測る**

フォロワー数やいいね数は、スコアの一要素に過ぎません。最も重要なのは、あなたの過去の行動から予測される「エンゲージメント確率」です。だからこそ、フォロワー500人のツイートが、100万人のツイートより上に表示されることがあるのです。

## まとめ

Heavy Rankerは、Xアルゴリズムの最終判定層として、あなたのタイムラインを構築しています。

**重要ポイント:**

1. **6,000の特徴量** - 著者、ツイート、エンゲージメント履歴を多角的に分析
2. **15種類の確率予測** - あなたがどう反応するかを高精度で予測
3. **重み付けスコア計算** - ポジティブ/ネガティブアクションを統合
4. **パーソナライゼーション** - 一人ひとり異なるスコアが計算される

**Heavy Rankerを理解することで得られるもの:**

- なぜ特定のツイートが表示されるのか理解できる
- 自分のツイートの表示を最適化する戦略が立てられる
- アルゴリズムに「評価される」のではなく、「活用する」視点が得られる

次回は、Heavy Rankerが重視する「TweepCred」について、さらに深く掘り下げます。
